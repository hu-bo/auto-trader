# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-02-01

### Added
- Initial release
- Core `CasdoorServer` class with full OAuth 2.0 support
- JWT token parsing and validation
- User management (get, list, update, delete)
- Token exchange and refresh
- Flask integration with middleware and decorator
- FastAPI integration with dependency injection and middleware
- Django integration with middleware and decorator
- Both sync and async API support
- Complete type hints
- Comprehensive documentation and examples
