# OKX 下单参数指南

## tdMode — 交易模式

下单时必须指定，取值取决于账户模式：

| 账户模式 | 场景 | 取值 |
|---------|------|------|
| 现货模式 | 币币和期权买方 | `cash` |
| 合约模式 | 逐仓杠杆 | `isolated` |
| 合约模式 | 全仓杠杆 | `cross` |
| 合约模式 | 币币 | `cash` |
| 合约模式 | 全仓交割/永续/期权 | `cross` |
| 合约模式 | 逐仓交割/永续/期权 | `isolated` |
| 跨币种保证金模式 | 全仓币币 | `cross` |
| 跨币种保证金模式 | 全仓交割/永续/期权 | `cross` |
| 组合保证金模式 | 全仓币币 | `cross` |
| 组合保证金模式 | 全仓交割/永续/期权 | `cross` |

---

## clOrdId — 客户自定义订单ID

- 用户自定义的唯一 ID，用于识别订单
- 传入后会在返回参数中体现，可用于查询/撤销/修改订单
- **不能与当前所有挂单的 clOrdId 重复**

---

## posSide — 持仓方向

- **买卖模式**：非必填，如填写只能选 `net`
- **开平仓模式**：必填，只能选 `long` 或 `short`

开平仓模式下 `side` + `posSide` 组合规则：

| 操作 | side | posSide |
|------|------|---------|
| 开多 | `buy` | `long` |
| 开空 | `sell` | `short` |
| 平多 | `sell` | `long` |
| 平空 | `buy` | `short` |

> 组合保证金模式：交割和永续仅支持买卖模式

---

## ordType — 订单类型

**普通委托：**

| 类型 | 说明 |
|------|------|
| `limit` | 限价单，需指定 `sz` 和 `px` |
| `market` | 市价单；币币/杠杆为市价吃单；交割/永续为最高买/最低卖价委托（遵循限价机制）；期权不支持；会多冻结 5% 计价币资产 |

**高级委托：**

| 类型 | 说明 |
|------|------|
| `post_only` | 只做 maker，若会吃单则全部撤销 |
| `fok` | 全部成交或立即取消 |
| `ioc` | 立即成交并取消剩余，不展示在深度列表 |
| `optimal_limit_ioc` | 市价委托立即成交取消剩余，仅适用于交割/永续合约 |

---

## sz — 交易数量

| 场景 | sz 含义 |
|------|---------|
| 币币/杠杆限价买入或卖出 | 交易货币数量 |
| 币币杠杆市价买入 | 计价货币数量 |
| 币币杠杆市价卖出 | 交易货币数量 |
| 币币市价单 | 由 `tgtCcy` 决定单位 |
| 交割/永续/期权买入或卖出 | 合约张数 |

---

## reduceOnly — 只减仓

- 设为 `true` 时，订单只会减少持仓，不会新开仓位
- 仅适用于**合约模式**和**跨币种保证金模式**
- 仅适用于**币币杠杆**，以及买卖模式下的**交割/永续**
- 注意：交割/永续在开平仓模式下，所有平仓单默认具有只减仓逻辑，不受此字段影响

限制规则：
- 杠杆：所有反方向挂单币数 + 当前只减仓下单数量 ≤ 仓位资产；负债还完后剩余委托不会反向开仓，而是进行币币交易
- 交割/永续：当前只减仓下单张数 + 价格时间优先于当前只减仓挂单张数总和 ≤ 持仓数量

---

## tgtCcy — 市价单委托数量单位

仅适用于**币币市价下单**：

| 取值 | 含义 |
|------|------|
| `base_ccy` | 交易货币 |
| `quote_ccy` | 计价货币 |

注意事项：
- 输入数量 > 可买/可卖数量时，系统按最大可买/可卖数量成交
- 输入数量 ≤ 可买/可卖数量时，若市场波动过大导致锁定余额不足，系统按"能买多少买多少"原则调整数量

---

## px — 委托价格

期权下单时，委托价格须为 `tickSz` 的整数倍，取整规则（以 `tickSz = 0.0005` 为例）：

- 余数 > 0.00025，或委托价格 < 0.0005 → **向上取整**
- 余数 ≤ 0.00025，且委托价格 > 0.0005 → **向下取整**

---

## 附带止盈止损

规则：
1. 只有订单**完全成交**后才会生成止盈止损策略订单
2. `tgtCcy=base_ccy` 的市价买单 和 `tgtCcy=quote_ccy` 的市价卖单，**不支持**附带止盈止损
3. `tpOrdKind=limit` 且只有一笔单边止盈时，`attachAlgoClOrdId` 可作为 `clOrdId` 查询

**分批止盈规则：**

| 规则 | 错误码 |
|------|--------|
| 每笔止盈止损订单仅支持单向（slTriggerPx/slOrdPx 与 tpTriggerPx/tpOrdPx 只能填一组） | 51076 |
| 同一订单的止盈触发价类型 (tpTriggerPxType) 必须一致 | 51080 |
| 同一订单的止盈触发价 (tpTriggerPx) 不能相等 | 51081 |
| 止盈订单数量不能为空 | 51089 |
| 分批止盈数量之和必须等于订单委托数量 | 51083 |
| 分批止盈委托不能超过 10 笔 | 51079 |
| 币币/杠杆不支持开启"开仓价止损" | 51077 |
| 止损委托单不能超过 1 笔 | 51084 |
| 开启"开仓价止损" (amendPxOnTriggerType=1) 时，止盈委托单必须 ≥ 2 笔 | 51085 |
| 同一订单分批止盈类型必须一致 | 51091 |
| 同一订单分批止盈委托价不能相等 | 51092 |
| 限价止盈的 tpOrdPx 不能为 -1（市价） | 51093 |
| 币币、杠杆和期权不支持限价止盈 | 51094 |

## stpMode — 强制自成交保护 (STP)

系统以**母账户维度**实施，同一母账户下所有子账户均无法自成交。默认使用账户层面的 `acctStpMode`（默认值 `cancel_maker`）。

| 模式 | 行为 |
|------|------|
| `cancel_maker` | 撤销 Maker 订单，Taker 继续与下一个订单成交（默认） |
| `cancel_taker` | 撤销 Taker 订单；若 Maker 不是深度第一，Taker 会被部分成交后撤单 |
| `cancel_both` | 同时撤销 Taker 和 Maker；不支持 FOK 订单 |

> STP 模式始终基于 taker 订单中的配置，不会导致延迟。

---

## tradeQuoteCcy — 计价货币

特定国家/地区用户下单时必填，否则报错 51000。取值必须来自 `GET /api/v5/account/instruments` 返回的 `tradeQuoteCcyList` 枚举值。

---

## 订单限速

- **50个 / 2s**
- 限制维度：User ID + Instrument ID
- REST 和 WebSocket 的下单及批量下单接口**共享**此限速
